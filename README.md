# Zomato Restaurant Data Analysis 📊

## Project Overview
This project focuses on analyzing the Zomato restaurant dataset using Microsoft Excel to discover insights about restaurants, customer ratings, cuisines, pricing, and online food delivery.

## Dataset Information
- Total Records: 9,551
- Total Columns: 21
- Cities: 141
- Countries: 15
- Restaurants: 7,446 unique restaurant names

## Tools & Skills
- Microsoft Excel
- Data Cleaning
- Excel Formulas
- Pivot Tables
- Data Visualization
- Charts and Dashboard Creation

## Analysis Performed
1. Data cleaning and preparation.
2. Handling missing values and duplicate records.
3. Analyzing restaurant ratings.
4. Comparing restaurants across cities.
5. Analyzing popular cuisines.
6. Studying average cost for two people.
7. Analyzing online delivery and table booking.
8. Creating charts and visual summaries.

## Key Dataset Insights
- New Delhi has the highest number of restaurant listings.
- North Indian is the most frequently listed cuisine.
- 2,451 restaurants offer online delivery.
- 1,158 restaurants offer table booking.
- 7,403 restaurants have a rating above zero.
- Average rating among rated restaurants is approximately 3.44.

## Project Objective
The objective is to develop practical data analytics skills and understand how restaurant data can be transformed into meaningful business insights.
